# Haku Auto-Research — Operator Hypotheses v001

작성 기준: 2026-07-31  
직접 의미 검토: 11편 완료, 1편 2차 검토, Golden 8 별도  
권리: 공개 레퍼런스 분석 전용. 레퍼런스 영상은 결과물 재료로 사용하지 않는다.

이 문서는 “Haku처럼 보이는 효과 목록”이 아니다. 서로 다른 작품 3편 이상에서
반복되고, 각 작품에서 기능까지 설명할 수 있는 편집·연출 결합만 임시 범용
Operator 후보로 올린다. 한 작품에만 나온 선택은 격리한다.

## 현재 승격 가능한 공통 후보

### 1. `sensory-scale-relay`

같은 사건 또는 감정 축을 환경 원경→인물 중경→손·눈·발·물성 디테일로
옮긴다. 단순 크기 변화가 아니라 매 거리마다 새 정보를 더해야 한다.

- 근거: `DZsDeJ-TeM_`, `DWuZaCfE-WF`, `DZXiQ_jz2tg`,
  `DQi8EW5k0-o`, `DZFOV3Qz7Gs`
- 소재 조건: 같은 인물·소품·빛을 여러 거리에서 촬영한 커버리지
- 실패 조건: 같은 행동을 크롭만 바꿔 반복, 디지털 줌으로 가짜 거리 생성
- 광고 사용: 제품 환경→사용 행동→물성 디테일 또는 인물 무드→제품 접촉

### 2. `density-wave-release`

전체를 같은 속도로 자르지 않고 `burst→breath`, `breath→burst→signoff`,
또는 `image island→black breath`처럼 밀도에 큰 파동을 만든다.

- 근거: `DWuZaCfE-WF`, `DQi8EW5k0-o`, `DZXiQ_jz2tg`,
  `DOdPyazk0k7`
- 소재 조건: 한 장으로 버티는 강한 이미지와 빠르게 압축할 보조 이미지가 모두 필요
- 실패 조건: 모든 숏을 0.2초로 통일, 느린 구간에 임의 줌을 넣어 쉬지 못하게 함
- 광고 사용: 감각 증거 폭주 뒤 제품·얼굴·카피를 읽히게 하는 release

### 3. `motif-state-return`

같은 장소·사람·소품을 그대로 반복하지 않고 상태를 바꿔 되돌린다.
시작과 끝의 차이가 감정 또는 광고 명제를 만든다.

- 근거: `DZsDeJ-TeM_`의 뜰채·산 복귀,
  `DRUNg3UE0c2`의 빈 방→인물→빈 방,
  `DSxLPd6k6X7`의 두 사람→한 사람/부재→두 사람
- 소재 조건: 동일 축의 전후 상태 또는 반복 촬영이 있어야 함
- 실패 조건: 같은 클립을 단순 반복, 변화 없는 책갈피
- 광고 사용: 사용 전→경험→사용 후, 제품 없음→사용→제품이 남긴 변화

### 4. `afterimage-handoff`

행동이나 피사체가 사라진 뒤 동일 표면·공간·빛을 남겨 시청자가 빠진 대상을
계속 기억하게 한다.

- 근거: `DOTAz9lE11A`의 손→빈 수면,
  `DRUNg3UE0c2`의 인물→빈 방,
  `DSxLPd6k6X7`의 사람→빈 바다,
  `DOdPyazk0k7`의 이미지 섬→암전
- 소재 조건: 피사체가 사라져도 스스로 버티는 표면과 구도
- 실패 조건: 빈 구간을 정지 오류로 제거, 다른 B-roll이나 효과로 즉시 채움
- 광고 사용: 제품 사용 뒤 피부·공간·물성에 남은 결과를 여운으로 증명

### 5. `action-as-edit-spine`

효과나 카메라 흔들림이 아니라 실제 행동의 준비→실행→완료 또는
주도권 교대가 컷 포인트와 시퀀스 spine을 결정한다.

- 근거: `Da24ipMTXu4`의 그림 역할 교대,
  `DYql5NyTBeO`의 몸 퍼포먼스→카피,
  `DZFOV3Qz7Gs`의 불꽃 놀이 커버리지,
  `DJKFdm6TKL1`의 걷기→연주→모자 던지기
- 소재 조건: 각 숏 안에 시작과 끝이 보이는 실제 행동
- 실패 조건: 행동 중간을 임의로 잘라 움찔하게 만들기, 의미 없는 속도 램프
- 광고 사용: 제품 기능을 설명하기 전 실제 사용 행동으로 증명

### 6. `relationship-through-blocking`

표정 클로즈업보다 사람 수, 거리, 자리 교대, 공동 표면, 소품 전달로 관계를
보여준다.

- 근거: `Da24ipMTXu4`, `DZsDeJ-TeM_`, `DZFOV3Qz7Gs`,
  `DSxLPd6k6X7`
- 소재 조건: 두 사람이 같은 행동·표면·소품을 공유하거나 접근·이탈하는 커버리지
- 실패 조건: 무관한 두 인물 숏을 교차해 관계를 가정, 표정만 과도하게 의존
- 광고 사용: 함께 쓰는 제품, 협업 서비스, 여행·우정·커플 캠페인

### 7. `stable-frame-internal-change`

카메라를 움직이지 않고 프레임 안의 인물 궤적, 그림 생성, 피사체 유무,
빛·물성 변화로 편집을 만든다.

- 근거: `Da24ipMTXu4`, `DYql5NyTBeO`, `DOTAz9lE11A`,
  `DRUNg3UE0c2`
- 소재 조건: 배경 축이 안정되고 내부 변화가 작은 화면에서도 읽혀야 함
- 실패 조건: 정적인 숏이라는 이유로 디지털 줌·흔들림을 자동 추가
- 광고 사용: 전후 비교, 사용 과정, 성분·촉감, 퍼포먼스 증명

## 현재 강한 금지 규칙

1. 자동 컷 검출값을 실제 숏 수로 사용하지 않는다.
2. 긴 숏에 자동 확대·축소·움찔을 넣지 않는다.
3. 검은 화면과 빈 풍경을 오류로 자동 삭제하지 않는다.
4. 예쁜 장면만 모으지 말고 반복 인물·행동·빛·소품 중 하나로 순서를 정한다.
5. 모든 작품에 같은 컷 밀도나 같은 전환을 적용하지 않는다.
6. 인물 행동 중간의 방향·속도 불연속은 미학으로 정당화하지 않는다.
7. 레퍼런스 원본을 proof나 최종 결과 재료로 사용하지 않는다.
