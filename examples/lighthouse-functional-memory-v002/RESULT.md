# Lighthouse Functional Memory v002

## 판정

직전 버전은 Haku의 안전한 감정 흐름만 남은 순차 몽타주라 실패로 취급했다. 이 버전은 요청된 기술 문법을 좁게 검증한 연구 결과로 `pass`, 사용자 평가는 아직 `pending`이다.

## 11.2초 편집 구조

- `00:00.00~00:02.00`: 12f → 11f → 11f → 16f 미세 컷. 촉감, 장소, 앨범, 촉감 귀환이 각각 새 역할을 추가한다.
- `00:02.00~00:02.80`: `the day stayed in pieces`. 이후 분절 화면을 실제로 설명하는 한 문장만 사용한다.
- `00:02.80~00:05.60`: 등대(장소) → 사과와 피크닉 표면(촉감) → 앨범(기억 물체) → 세 사람의 시선(관계)이 순차로 누적된다.
- `00:05.60~00:11.20`: 모든 작은 화면을 걷어내고, 실제 즉석사진이 올라오는 연속 촬영 전체 화면으로 회수한다.

## 수정 검수

첫 렌더는 회수 직전 패널이 4프레임 동안 함께 어두워져 멈칫처럼 보였으므로 탈락시켰다. 최종 렌더는 2프레임의 최소 정리만 남기고 즉시 전체 화면으로 전환한다. 최종 자동 검사에서 중복 프레임, 정지 구간, 가짜 확대/축소, 스케일 리셋, 마지막 프레임 패딩, 자동 실패 항목은 없다. 남은 움직임 후보는 선언된 작은 영상 등장 프레임과 일치한다.

## 한계

실제 플레이어의 전속도 재생을 캡처한 검수는 수행하지 못해 `full_playback_reviewed=false`로 유지했다. 계정 스타일의 최종 성공 여부와 Operator 승격은 사용자 승인 전까지 확정하지 않는다.
