2. `02-unedited-group-landscape.mp4` — 음식·와인·따르기 행동이 있는 무편집 원테이크.
3. `03-unedited-wine-group-landscape.mp4` — 네 사람의 건배와 대화가 있는 무편집 원테이크.

6. `06-haku-tool-proof.mp4` — 화면 내부 밀도 상승과 그룹 release를 적용한 Haku Tool 검증본.
7. `07-plain-vs-proof.mp4` — 왼쪽 plain / 오른쪽 proof 비교.

## 확인할 시점

- `00:02.20`: 오른쪽 proof에 세로 반응 창이 생기며 따르기 행동과 감정이 연결되는가.
- `00:03.40`: 반응 창이 사라지고 그룹 창이 나타날 때 복잡하거나 움찔하지 않는가.
- `00:04.60`: 작은 그룹 창의 행동이 다음 원본 프레임의 전체 화면으로 자연스럽게 이어지는가.
- `00:04.60–00:08.40`: 네 사람의 건배와 대화가 앞의 밀도를 충분히 풀어 주는가.
- 전체적으로 proof가 plain보다 더 연출되고 감정이 누적되는지, 아니면 창이 과한지.
