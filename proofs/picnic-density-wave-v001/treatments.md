# Picnic density wave treatments

## Safe — sequential sensory relay

- Full-frame tactile food and wine detail.
- Full-frame pour action owner.
- Full-frame individual pleasure reaction.
- Full-frame four-person toast and conversation.
- No in-frame panel.

This is the cleanest observational edit and the fallback when panel density does not add meaning.

## Recommended — sequential social-density windows

- Keep the tactile food-and-wine premise full frame.
- Use the visible wine pour as the causal full-frame base.
- Add one bounded portrait reaction window for 1.20 seconds; remove it before the next window appears.
- Add one bounded group-toast preview for 1.40 seconds.
- Continue the exact next source frame of that group preview at full size for the toast and conversational exhale.
- Keep the canvas landscape so all four participants remain readable.

This tests one hypothesis: progressive in-frame social information can make the scale relay feel authored without repeating the v004 simultaneous-window clutter.

## Experimental — simultaneous social field

- Keep pour, reaction, and group-preview movement visible together for a short peak.
- Release to the group toast.

This is not selected. The sources are already visually busy with hands, glasses, faces, food, candlelight, and shallow depth; simultaneous windows would probably reduce relationship readability and repeat the collage problem already found in the park proof.
