# Visual critique

- Proof storyboard: directly reviewed.
- Result: information preserved, aesthetic gate failed; do not enter the proof-cycle ledger.

`fit-single` correctly restores the complete four-person toast that v001 deleted. The fixed non-cover layout is technically honest and avoids animated reframing. However, the last cut changes from a full-height portrait to a narrow horizontal strip surrounded by a large dark field. The viewer notices image shrinkage before relationship expansion.

This layout may be valid when a project deliberately uses horizontal memory windows, but this proof did not establish that grammar earlier. The source session is predominantly landscape. The next revision should use a 16:9 canvas for the entire comparison, keep the landscape detail/action/group shots native, and apply one fixed crop only to the vertical reaction shot.
