# Haku Tool Private Repository Release

This repository is the compact, reproducible development package for the Haku-informed video-editing harness.

## Included

- `skill-package/haku-tool`: Codex skill, routing rules, renderers, validators, schemas, and tests.
- `timeline-grammar`, `semantic-reviews`, `synthesis`, and `state`: evidence and AutoResearch state without public reference media.
- `proofs` and `tests`: compact technical fixtures and review metadata.
- `examples/lighthouse-functional-memory-v002`: the latest user-review candidate demonstrating semantic microcuts, restrained copy, role-distinct live panels, and full-frame recovery.

## Excluded

- Public `@haku_.photo` source media.
- Downloaded raw stock footage and user footage.
- Music binaries, caches, temporary renders, and large review atlases.

Reference media is analysis-only. Proofs must use owned, commissioned, permissioned, or appropriately licensed source material. User acceptance is never inferred from an internal research pass.
