# haku_tool 연출 분석 분류표

## 사용법

각 Reel과 시퀀스에 아래 항목을 태깅한다. 자동 측정값과 시각 판정을 구분하고, 시각 판정에는 `low`, `medium`, `high` 신뢰도를 기록한다.

## 1. 서사와 감정

- `sensory-hook`: 의미보다 감각을 먼저 제시
- `character-hook`: 얼굴·몸짓·시선으로 시작
- `object-hook`: 사물 하나를 질문처럼 제시
- `environment-hook`: 날씨·빛·공간으로 시작
- `accumulation`: 파편을 누적해 감정 상승
- `suspension`: 정지·암전·침묵으로 감정 보류
- `reveal`: 인물·관계·공간의 의미 공개
- `release`: 넓은 공간·긴 호흡으로 해방
- `afterimage`: 설명 대신 마지막 이미지로 잔상

## 2. 인물 연출

- 인원: 없음, 1명, 2명, 군중
- 얼굴 노출: 없음, 부분, 명확
- 시선: 카메라, 상대, 화면 밖, 아래, 위
- 동작: 걷기, 달리기, 멈춤, 뒤돌기, 손 뻗기, 던지기, 만지기
- 미세 행동: 머리카락, 옷자락, 손가락, 호흡, 눈 깜박임
- 관계 거리: 고립, 병치, 접근, 교차, 이탈
- 연기 강도: 관찰적, 자연스러운 수행, 명시적 퍼포먼스

## 3. 카메라 문법

- 크기: EWS, WS, MS, MCU, CU, ECU
- 높이: 바닥, 허리, 눈, 하이앵글, 로우앵글
- 움직임: 고정, 핸드헬드, 팬, 틸트, 트래킹, 오빗, 푸시, 풀
- 운동 주체: 카메라, 피사체, 배경, 복합
- 안정성: 고정, 미세 흔들림, 의도적 거침
- 렌즈 인상: 광각 공간감, 표준 관찰, 망원 압축, 매크로 물성

## 4. 공간과 구도

- 중심, 삼분할, 대칭, 프레임 인 프레임
- 전경 차폐, 음영 실루엣, 반사, 유리·물 투과
- 양의 공간과 음의 공간의 비율
- 깊이 층: 전경, 중경, 배경
- 이동 방향: 좌→우, 우→좌, 전진, 후퇴, 상→하, 하→상
- 연결 공간: 문, 복도, 계단, 창, 운동장, 물가, 하늘

## 5. 빛·색·물성

- 광원: 직사광, 역광, 측광, 흐린 날, 실내 혼합광, 야간 인공광
- 노출: 정상, 하이라이트 우선, 그림자 우선, 실루엣
- 색온도: 냉색, 중립, 온색, 혼합
- 팔레트: 청록, 녹색, 황금, 파랑, 흰색, 저채도
- 물성: 물, 유리, 피부, 천, 금속, 먼지, 비, 안개, 잎, 머리카락
- 시간감: 새벽, 낮, 골든아워, 블루아워, 밤

## 6. 시간과 편집

- 하드컷, 매치컷, 점프컷, 암전, 플래시
- 프리즈, 스터터, 반복, 역재생
- 속도: 느림, 실시간, 가속, 램프
- 마이크로컷 그리드: 0.13, 0.20, 0.40, 0.80초 계열
- 시퀀스 밀도: 상승, 일정, 하강, 파동
- 반복 방식: 동일 프레임, 같은 대상, 같은 형태, 같은 행동

## 7. 전환의 의미

- `shape-match`: 윤곽·원·선·곡선 연결
- `color-match`: 동일 색 덩어리 연결
- `motion-match`: 방향·속도·몸짓 연결
- `scale-jump`: ECU↔WS 대비
- `texture-bridge`: 물·피부·천·구름 등 물성 연결
- `semantic-rhyme`: 다른 대상이 같은 감정을 수행
- `temporal-echo`: 과거·현재처럼 보이는 반복

## 8. 사운드와 영상

- 음악 온셋 컷
- 멜로디 프레이즈 경계
- 현장음 선행 또는 잔향
- 충격음, 리버스 스웰, 저역 펄스
- 소리 없는 정지 구간
- 이미지가 소리를 설명하는지, 소리가 이미지를 재해석하는지

## 9. 촬영 커버리지

각 규칙을 재현하려면 다음을 기록한다.

- 필수 피사체와 장소
- 필요한 샷 크기 수
- 행동 전후 핸들
- 동일 동작의 각도 수
- 빛·날씨 의존성
- 반복해야 할 모티프
- 편집으로 대체 가능한 요소
- 반드시 재촬영해야 하는 요소

## 10. 증거 형식

모든 태그는 다음 증거를 가진다.

- `reel_id`
- `time_start`, `time_end`
- `frame_path`
- `observation`
- `directing_inference`
- `transferable_rule`
- `confidence`
- `counterexample`
