# haku_tool 연출 유형

## 사용 원칙

아래 유형은 효과 프리셋이 아니라 연출과 촬영 커버리지의 묶음이다. 사용자 촬영본이 최소 조건을 충족할 때만 선택한다. 서로 다른 유형의 표면 장치를 무작정 섞지 않는다.

## 1. sensory-flash-montage

- 기능: 여러 감각 파편을 짧게 충돌시켜 기억·계절·청춘의 밀도를 만든다.
- 신규 30편의 주 유형: 11, 19, 31, 39
- 훅: 눈·물·불꽃·손·구름 같은 ECU/CU를 0.13~0.40초대로 시작
- 연출: 대상보다 물성·빛·몸의 일부를 먼저 보여 주고, 뒤늦게 사람이나 공간을 공개
- 편집: 모든 컷을 빠르게 하지 말고 플래시 군집과 호흡 구간을 분리
- 필수 촬영본: 서로 다른 스케일 12개 이상, 감각 인서트 6개 이상, 반복 모티프 2개 이상
- 금지 조건: 유사한 풍경 와이드만 있거나 인서트가 부족한 경우
- 실패 징후: 컷은 빠르지만 이미지끼리 형태·물성·감정 관계가 없음

## 2. action-prism-human-narrative

- 기능: 한 사람 또는 관계의 작은 행동을 여러 거리·각도·반응으로 분해해 서사를 만든다.
- 신규 30편의 주 유형: 12, 14, 22, 26, 27, 35, 38
- 훅: 행동 직전의 표정·손·등·소품 또는 공간의 기다림
- 연출: 걷기, 찍기, 건네기, 연주, 장난, 달리기처럼 완결 가능한 작은 행동을 설계
- 편집: 행동의 원인 → 수행 → 반응 → 공간적 결과를 유지하며 감각 인서트를 사이에 배치
- 필수 촬영본: 동일 행동의 WS/MS/CU, 손·발·눈 중 2종, 상대 반응 또는 환경 반응
- 금지 조건: 결과 장면만 있고 행동 시작·종료 핸들이 없는 경우
- 실패 징후: 예쁜 B-roll 사이에서 인물이 무엇을 원하는지 보이지 않음

## 3. seasonal-poetic-essay

- 기능: 계절·빛·장소·이동을 반복 모티프로 묶어 정서적 여정을 만든다.
- 신규 30편의 주 유형: 17, 20, 21, 23, 30, 33, 36
- 훅: 창, 수면, 나뭇잎, 하늘, 그림자처럼 장소의 감각
- 연출: 같은 인물의 이동 또는 같은 계절 물성을 서로 다른 공간에 반복
- 편집: 장면의 논리보다 모티프의 귀환과 공간 확장으로 구조화
- 필수 촬영본: 장소 3곳 이상 또는 한 장소의 시간대 3단계, 반복 모티프 3회, 종료용 EWS/WS
- 금지 조건: 장소 변화도 시간 변화도 없이 유사 풍경만 반복되는 경우
- 실패 징후: 분위기는 있으나 시작·변화·귀환이 없어 슬라이드쇼처럼 보임

## 4. graphic-layout-memory-log

- 기능: 작은 프레임, 분할 화면, 타임코드, 독자 문구를 이용해 기억·기록물의 형식을 만든다.
- 신규 30편의 주 유형: 16, 25, 29, 32
- 훅: 검정 여백 속 작은 영상, 반복되는 표식, 독자적인 제목 체계
- 연출: 같은 사건의 서로 다른 조각을 기록물처럼 수집하고 화면 배치를 사전에 설계
- 편집: 프레임 크기·위치·반복 간격 자체가 리듬이 되도록 구성
- 필수 촬영본: 가로·세로·세부 구도가 섞인 클립 8개 이상, 고유 그래픽 규칙 1개
- 금지 조건: 레퍼런스의 문구·로고·타임코드 디자인을 그대로 모사하는 경우
- 실패 징후: 여백과 분할이 의미 없이 화면을 작게 만들기만 함

## 5. process-observation

- 기능: 만들기·그리기·연주 같은 과정의 진척을 관찰해 몰입을 만든다.
- 신규 30편의 주 유형: 18
- 훅: 완성 전 상태 또는 도구의 첫 접촉
- 연출: 시작 상태, 반복 작업, 선택·수정, 완성 상태를 실제 순서로 촬영
- 편집: 긴 수행 쇼트와 도구·손·결과 인서트를 번갈아 사용
- 필수 촬영본: 과정 4단계, 손과 도구 CU, 작업자 MS, 결과 WS/CU
- 금지 조건: 완성 결과만 있고 과정이 없는 경우
- 실패 징후: 손만 반복되고 무엇이 변했는지 보이지 않음

## 6. minimal-single-idea

- 기능: 한 행동·사물·빛·구도를 오래 밀어붙여 강한 한 문장의 영상을 만든다.
- 신규 30편의 주 유형: 13, 15, 24, 28, 34, 37, 40
- 훅: 실루엣, 눈, 손, 불꽃, 꽃, 모자처럼 단번에 읽히는 핵심 이미지
- 연출: 하나의 시각 사건에 시작·변형·잔상을 만든다.
- 편집: 2~6개 쇼트, 충분한 지속 시간, 한 번의 명확한 스케일 변화
- 필수 촬영본: 중심 행동 또는 빛 변화 1개, 보조 인서트 1~2개, 종료 이미지 1개
- 금지 조건: 중심 사건 자체가 약해 여러 효과로 감춰야 하는 경우
- 실패 징후: 짧고 느린 것이 아니라 정보가 부족한 영상이 됨

## 선택 우선순위

1. 완결된 인물 행동과 다중 거리 커버리지가 있으면 `action-prism-human-narrative`.
2. 강한 단일 사건은 있으나 커버리지가 적으면 `minimal-single-idea`.
3. 감각 인서트와 스케일 다양성이 충분하면 `sensory-flash-montage`.
4. 장소·시간·모티프의 귀환이 있으면 `seasonal-poetic-essay`.
5. 실제 제작 과정이 있으면 `process-observation`.
6. 독자적인 기록 형식이 콘셉트의 중심이면 `graphic-layout-memory-log`.

유형 선택 뒤에도 보조 장치는 최대 두 개만 빌린다. 예를 들어 인물 서사에 감각 인서트와 마지막 공간 해방을 더할 수 있지만, 타임코드·분할 화면·마이크로컷·자막 에세이를 동시에 넣지 않는다.
