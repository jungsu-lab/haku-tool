# haku_tool 40-Reel 분석 계획

## 목표

haku_.photo의 특정 영상 표면을 복제하지 말고, 반복 가능한 연출 판단을 촬영·편집·사운드 규칙으로 변환한다. 기존 10개에서 세운 가설을 신규 30개로 검증해 우연한 장치를 스타일 규칙으로 오인하지 않는다.

## 코퍼스 설계

- 가설 세트: 기존 Reel 10개
- 검증 세트: 중복 없는 신규 Reel 30개
- 총 코퍼스: 40개
- 권리: `public-reference-only`
- 사용 범위: 로컬 분석, 키프레임, 수치, 규칙
- 금지: 원본 영상·음악·인물·문구를 사용자 결과물이나 저장소에 재사용

신규 30개의 결과를 보기 전에 기존 10개에서 발견한 가설을 고정한다.

1. 0.4초 안팎의 마이크로컷 그리드가 반복되는가?
2. 정지 프레임과 짧은 움직임을 교대하는가?
3. 인물 행동보다 빛·물·바람·사물의 감각 파편으로 감정을 시작하는가?
4. 서로 다른 공간을 형태·방향·색·동작으로 연결하는가?
5. 결말에서 컷 밀도를 낮추고 공간을 크게 열어 주는가?

## 분석 층위

### A. 전수 정량 분석

40개 모두에서 다음을 측정한다.

- 길이, 해상도, FPS, 오디오 유무
- 컷 수, 컷 길이 분포, 0.25/0.5/1초 미만 비율
- 프리즈 비율과 연속 구간
- 검정·백색 프레임, 밝기 플래시
- 움직임 중앙값·상위 10%, 줌 후보
- 오디오 온셋, 템포 후보, 컷–온셋 거리
- 영상 시작·중간·끝의 컷 밀도 변화

### B. 전수 시각 분석

Reel마다 16~24프레임 스토리보드와 컷 대표 프레임을 검토한다.

- 첫 프레임과 첫 3초의 훅
- 인물·사물·환경의 비중
- 샷 크기와 카메라 높이
- 인물의 미세 행동과 시선
- 카메라·피사체·배경 움직임
- 화면 방향과 그래픽 매치
- 자연광, 역광, 노출 변화, 색온도
- 계절·날씨·물성 모티프
- 감정의 도입·상승·정지·해방
- 마지막 이미지와 잔상

### C. 시퀀스 문법 분석

개별 쇼트가 아니라 2~8개 쇼트 묶음에서 기능을 찾는다.

- 감각 파편으로 여는 `sensory cold open`
- 대상의 부재를 주변 흔적으로 보여 주는 `absent-subject setup`
- 한 동작을 거리·각도·시간으로 분해하는 `action prism`
- 형태·색·방향으로 공간을 건너는 `graphic bridge`
- 같은 이미지를 변형 반복하는 `motif echo`
- 빠른 파편 뒤 넓은 쇼트로 푸는 `spatial release`

## 규칙 승격 기준

- `signature`: 40개 중 24개 이상 또는 서로 다른 3개 유형에서 각 5개 이상 확인
- `supporting`: 10~23개에서 확인
- `special-device`: 4~9개에서 확인되지만 효과와 조건이 명확함
- `coincidence`: 3개 이하이거나 증거가 불명확함

모든 규칙에 Reel ID, 타임코드, 반례, 필요한 촬영본, 실패 조건을 붙인다. 조회수만으로 규칙을 승격하지 않는다.

## 유형화

수치와 의미 태그로 Reel을 4~7개 유형으로 묶는다. 예상 유형은 가설일 뿐이며 데이터로 수정한다.

- 고속 감각 몽타주
- 인물 중심 청춘 서사
- 공간·계절 에세이
- 음악 협업형 플래시 몽타주
- 긴 호흡 관찰형
- 단일 행동·오브젝트 중심형

각 유형에 훅, 권장 길이, 필요한 커버리지, 컷 밀도, 사운드 방식, 실패 위험을 정의한다.

## haku_tool 모듈

분석 이후 다음 모듈을 독립적으로 호출할 수 있게 한다.

1. `analyze`: 레퍼런스와 사용자 촬영본의 연출·편집 특징 추출
2. `direct`: 콘셉트, 인물 동선, 미세 행동, 샷 리스트, 커버리지 설계
3. `edit`: 유형별 컷 구조, 프리즈, 반복, 속도, 그래픽 매치 레시피 생성
4. `grade`: 빛·계절·색온도·질감 목표와 Resolve 노드 지시 생성
5. `sound`: 원본 음악을 복사하지 않는 리듬·환경음·충격음 구조 생성
6. `critique`: 결과물을 연출·커버리지·편집·색·소리로 분리 평가

## 2차 자연영상 테스트

40개 분석 후 기존 자연영상에 동일한 v2 레시피를 다시 덮지 않는다. 추출된 유형 중 자연영상과 실제 커버리지가 맞는 유형 하나를 선택한다.

- 컷 타이밍 유사도
- 움직임·정지 대비
- 모티프 반복
- 스케일 변화
- 감정 곡선
- 사운드와 영상의 인과성

위 여섯 축을 별도로 채점한다. 촬영본 부족으로 실패한 축은 편집 실패와 분리해 보고한다.
